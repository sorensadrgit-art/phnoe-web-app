# Six films, six directions

Each folder is an independent editable HyperFrames project with its own index.html, DESIGN.md, local GSAP, package.json and exported video/poster. The outer résumé remains the same.

- about: Editorial movement manifesto
- experience: Industrial service dossier
- education: Anatomy field notebook
- projects: KineLab product demonstration
- skills: Playful dimensional type studio
- contact: Painted creative sign-off

Each film is eight seconds at 30 fps. Website playback is silent by design. Evidence and clinical limitations remain explicit. v5 is preserved.
